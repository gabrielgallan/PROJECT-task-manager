# Description

The frontend of the task manager: a Vite + React 19 single-page application that covers the operational flows (Tasks, Plans, Work Logs, and Categories) plus Dashboard, Reports, Settings, and Identity screens. It is built with Tailwind CSS 4 and shadcn/ui, uses React Router for routes and URL state, Jotai for small shared stores, and React Hook Form with Zod for forms.

# How to run locally

```bash
# 1. Enter the api directory
cd web

# 2. Install dependencies
pnpm install

# 3. Create and configure .env based on .env.example

# 4. Start the application
pnpm dev
```
